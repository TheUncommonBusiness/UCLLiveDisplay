READY FOR THE ROOM

Run the show.

  1. Open your Stage Displays. Assign a feed to each screen. Supporting displays can share one loop while the main stage holds a film.
  2. Build in Preview. Choose a template, edit its text, or create a loop. The live screen stays as it is.
  3. Launch when ready. Launch to Stage changes the selected feed in every open window assigned to it.
  4. Save a portable backup. Export show includes your templates, loops, settings, and uploaded media. Import it on another production computer.
