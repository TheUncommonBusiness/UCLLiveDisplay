# PowerPoint production backup

Use the latest files in the **For Production Team** folder supplied with the show.

- `PPT/01-ready-to-run.pptx`: 14 slides — ten finished holds followed by four event-app screens. Each stays up until you advance.
- `PPT/02-editable-presentation-kit.pptx`: 45 slides — holds first, then the template guide, editable title and content layouts, reusable elements, agenda, and app screens.

The production folder also includes all fourteen 4K MP4s, small GIF previews, transparent character accents, fonts, static PDF previews, and the operator guide. The ready-to-run deck has finished messages. Replace the editable kit’s content and agenda placeholders before showing those slides to guests.

## Edit and play

Duplicate the slide you want, then edit its text in Normal view. Title and hold layouts use embedded looping MP4s with separate editable text and branding. Content and agenda slides use still backgrounds with a small transparent character GIF in the bottom-right corner. GIFs animate in Slide Show mode.

Keep video backgrounds behind the editable text. The Selection Pane helps select individual objects. The two elements pages retain separate artwork for copying into new layouts.

Install the supplied fonts on the presentation computer and reopen PowerPoint. The MP4s already contain their finished typography and do not require fonts. The decks are 16:9; the finished movies are silent 3840 × 2160 H.264 files. Most movie loops run ten seconds; the light Editorial and Big Type app movies run fifteen seconds.

## Live display

Choose **Screens → Holds** or **Screens → Event app** in the [Stage Display console](https://theuncommonbusiness.github.io/UCLLiveDisplay/). All fourteen finished films are built in. Choose a display group, prepare the screen in Preview, then **Launch to Stage**.

Use the web console for independent display groups, remote control, slide loops, and live countdowns that change to a hold screen at zero. PowerPoint is the local backup and supports one slide show per computer.

The [production guide](../production-guide.html) covers setup, scaling, loops, remote sessions, and offline playback. Rehearse on the venue computer and displays before doors open.
