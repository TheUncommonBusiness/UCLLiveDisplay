# Uncommon Leaders Presentation Studio

Seven visual directions and an editable PowerPoint toolkit for Uncommon Leaders Live.

Open [the design gallery](designs/index.html) through the project's local web server, or view the [seven comparison boards](designs/previews/). The [PowerPoint](output/ucl-presentation-design-studio.pptx) contains all seven directions and the reusable content layouts. The [PDF preview](output/ucl-presentation-design-studio-preview.pdf) shows the slides without animation.

## Choose a direction

| Direction | Best use | Design approach |
| --- | --- | --- |
| 01 · Big Type | Opening statements and one important idea | Oversized Season type, chartreuse fields, cropped artwork |
| 02 · Modern Editorial | A complete keynote or leadership presentation | Asymmetrical grids, clear hierarchy, generous margins |
| 03 · Open Range Gallery | Quiet holds and art-led moments | One engraving takes the stage, with a restrained caption |
| 04 · Night Rodeo | Section breaks and evening holds | Forest backgrounds, enlarged engraving, chartreuse emphasis |
| 05 · The Field Guide | Frameworks and workshops | Numbered callouts, open diagrams, precise grids |
| 06 · Poster Wall | Event announcements and energetic openings | Angled print panels, bold color, layered artwork |
| 07 · Across the Horizon | Progress stories and wide stage compositions | Horizontal bands, contrasting halves, connected steps |

A useful combination is Modern Editorial for most content, Big Type for key ideas, and Night Rodeo between sections. Each direction has both an opening and a content example.

## Build your presentation

Duplicate the slides you need into a working deck. Replace bracketed copy and example chart data. Select artwork separately from text, or use PowerPoint's Selection Pane to find an object behind another object. Speaker notes explain each layout.

| Slides | Contents |
| --- | --- |
| 1 | Start here |
| 2–15 | Seven visual directions, two slides each |
| 16–22 | Section, agenda, big idea, quote, two-column text, text with image, three pillars |
| 23–29 | Comparison, before/after, three-step and five-step processes, timeline, matrix, cycle |
| 30–37 | Metrics, native bar and line charts, case study, exercise, summary, closing |
| 38–42 | Five animated holds |
| 43 | Reusable type, labels, rules, numbers, and color swatches |
| 44 | Twelve separate artwork elements |

The three background-only films have editable text over the video. The logo and hat-tip films contain their logo within the movie. All five films play automatically and loop until you advance.

PowerPoint runs one slide show at a time. Use the [production display console](https://theuncommonbusiness.github.io/UCLLiveDisplay/) for independent stage and supporting displays.

## Assets and fonts

Install the fonts in [output/fonts](output/fonts/) before editing on another computer. This deck uses Season Mix-TRIAL and Inter UCL.

The [elements folder](output/elements/) keeps the source SVGs and PNGs available outside PowerPoint. The elements slide retains their source resolution. SVG elements remain vector, while PNG artwork remains raster.

Download the [elements and fonts ZIP](ucl-design-elements.zip) to take the reusable assets to another computer.

The three new characters were created with built-in image generation using the Austin engraving as the style reference. Their originals, transparent cutouts, and [prompt set](characters/prompts.json) are in [characters](characters/).

| Character | Transparent cutout size |
| --- | --- |
| Longhorn | 1672 × 941 px |
| Roping cowboy | 1070 × 1470 px |
| Dancing cowgirl | 1024 × 1536 px |

The character concepts are not native 4K illustrations. Slide previews and embedded films use a 3840 × 2160 canvas. The hat-tip character footage is enlarged within its 4K composition.

This studio is a separate review package. The production console and existing production decks retain their current designs.
