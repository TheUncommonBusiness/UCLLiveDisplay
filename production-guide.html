Ready for the room.

The console controls the screens before and between sessions. Your presenters run their own presentations from their laptops.

Set up the displays

  1. Open the console in desktop Chrome on the production laptop. Connect the venue screens and extend the desktop in the computer’s display settings.
  2. Choose Stage Displays. The default setup has one Main display on the Main stage feed, with Support left and Support right sharing the Supporting displays feed.
  3. Click Open for each display. Move the new window onto its monitor and press F. Controls fade away. Press H to show or hide them.
  4. If available, Detect connected monitors lets you select a destination before opening a window. The browser still requires a click or keypress in each window to enter full screen. Allow pop-ups for this site when prompted. If full screen is blocked in a pop-up, use Open as browser tab, drag that tab into its own window, and press F.

Leave Stage Displays open. Choose a feed, edit a template in Preview, and click Launch to Stage. Every window assigned to that feed updates in place, including full-screen windows. Other feeds keep playing.

Control from another computer

  1. Choose Live session → Create live session on the controller. Wait until the show and uploaded media finish sharing.
  2. Copy a display link for each screen and open it on the stage laptop that drives that screen. Press F for full screen. Displays can share a feed or use independent feeds.
  3. Open the control link on another production computer to control the same session. Edit in Preview, then Launch. Keep the control link with the people running the show.

Connected stage laptops appear in Live session. Changes normally arrive on the next one-second check. A failed connection leaves the last launched program running, including local countdowns and cached loops. Remote changes require internet and resume when the connection returns. If two controllers launch at once, the older version is rejected so it cannot overwrite a newer cue.

The display link can receive screens but cannot launch or end the session. A stage laptop’s Fit/Fill/Stretch control changes that laptop’s view. Use the controller’s Stage Displays settings to change the shared defaults.

Use this computer locally leaves the session running for the other laptops and restores your previous local show. End session revokes its links. Sessions expire after 30 days. Shared uploads support 250 MiB per file, 50 files, and 1 GiB total.

Choose how a screen fits

ModeResult
FitShows the entire 16:9 design, with black bars if the display has another shape.
Fill / cropFills the monitor and crops the edges of the design.
StretchUses the whole monitor. Text and artwork change proportions.
MarginReduces the canvas by up to 10% to keep content away from the display edges.

Each display has its own scale and margin. For a new independent output, add a feed and assign it to that display. The default supporting pair shares one clock, so both windows stay on the same slide.

Templates, films, and loops

The selected presentation system uses Modern Editorial for content, Big Type for big ideas, and Night Rodeo for section breaks. Its 26 layouts match the PowerPoint toolkit. The four subtle 15-second background movies are identical in the web and PPT versions, with separate editable text and charts.

Built-in templates are shared with everyone who opens the site. Edit a template and save a copy for your show. In local mode, saved copies and uploads belong to this browser. In a live session, saved show changes and uploads are shared with the session.

The cowgirl hold has one hat-tip in each 15-second cycle, with a quiet pause between movements. Its character footage was generated at a lower resolution and composited into the 4K master with native vector branding. The Media library also includes a 4K logo film and three 4K background templates with editable words on top. Live artwork templates use vector logos and browser animation. Ambient makes the twinkles and sway visible, Gentle reduces the star motion, and Still freezes the artwork. Film backgrounds keep their original palette.

To make a loop, open Loops, add screens, choose their order, and set the hold duration and outgoing transition. Snap, Fade, Slide, Soft zoom, and Smart Morph are available. Smart Morph moves matching artwork between compatible templates. Images and video fade instead. Save the loop, then Launch to Stage.

To customize a slide inside a loop, first save its edited template to the library, then add that copy to the loop. Loops can contain your uploaded JPG, PNG, WebP, MP4, or WebM files. Videos play silently and repeat.

Countdowns and quick cues

A countdown starts when you launch it. Pause, reset, or add one minute from the live controls. Select the end screen in Preview before launch. At zero, the feed switches to that hold screen even if the operator console is closed.

A loop can also carry an overall countdown. Set its minutes in the loop builder. A value of zero leaves it repeating indefinitely. The loop and countdown have separate pause controls, so pausing the slide sequence does not pause the countdown.

Hold logo and Blackout act immediately on the selected feed. Restore picture brings back the running program after a blackout. It does not pause its timer.

Save and hand off

Export show creates a JSON file with the current setup and all uploaded media. Use Import show on another laptop. Import replaces that browser’s saved show, restarts loops, and pauses countdown timers until the operator starts them.

Opening the public site without a session link starts that computer’s local show. Use the control or display links from Live session to join the same show across computers.

The console caches the core files, built-in films, and team slides. Wait for Offline files ready, then rehearse with the network disconnected. Keep the site open during the event. Download the PowerPoint backups before arrival, since the decks are not part of the automatic browser cache. After a published update, refresh the console once to load the new controls. Existing stage windows keep their current document.

Before doors open

  • Check the actual venue displays, screen scaling, video playback, and full-screen behavior on the production laptop.
  • Turn off notifications and sleep. Keep power connected. Test a countdown finishing and a loop returning from its last slide to the first.
  • Export the show and keep the PowerPoint files plus 4K MP4s available locally.
